# project_group_3

### Як запустити на *nix:
```
git clone https://github.com/oliov/project_group_3
cd project_group_3
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python personal_assistant/main.py
```

### Як запустити на win:
```
git clone https://github.com/oliov/project_group_3
cd project_group_3
python3 -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
python personal_assistant/main.py
```
